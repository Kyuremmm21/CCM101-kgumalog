# Mission Reflection

## How has your GitHub portfolio improved after completing this mission?

After completing this laboratory activity, my GitHub portfolio has significantly improved in terms of organization, content quality, and professionalism. Before this mission, my repository mainly contained basic files from the previous laboratory. Now, it has a clearer and more structured layout with a dedicated folder for Laboratory 02 that includes properly named Markdown files and a screenshots folder.

One of the biggest improvements is the addition of technical documentation. I created files such as infrastructure-report.md, cloud-components.md, cloud-provider-comparison.md, and a detailed README.md. These documents show that I can investigate a Linux environment, identify cloud infrastructure components, and compare services from AWS, Microsoft Azure, and Google Cloud Platform. This makes my portfolio look more like the work of a real cloud computing student rather than just a collection of random files.

I also learned the importance of consistent committing and pushing. After every checkpoint, I made meaningful commit messages. This habit improved the version history of my repository and made it easier to track my progress. In addition, including screenshots and a simple cloud architecture diagram added visual evidence of my work, which makes the portfolio more complete and presentable.

Overall, this mission helped me understand that a strong GitHub portfolio is not only about uploading files but also about clear documentation, proper organization, and showing the process of learning. My repository now better reflects my growing knowledge in cloud computing and will serve as a stronger foundation for future laboratory activities and personal projects.
