# Cloud Provider Comparison

| Infrastructure Component              | AWS                  | Microsoft Azure              | Google Cloud Platform       |
|---------------------------------------|----------------------|------------------------------|-----------------------------|
| Compute                               | EC2                  | Virtual Machines             | Compute Engine              |
| Storage                               | S3 / EBS             | Blob Storage / Managed Disks | Cloud Storage / Persistent Disk |
| Networking                            | VPC                  | Virtual Network              | VPC                         |
| Identity and Access Management (IAM)  | IAM                  | Azure Active Directory / Entra ID | Cloud IAM                |


## Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.
Amazon Web Services (AWS) offers the broadest range of services. It has the largest number of services and features compared to Azure and Google Cloud, covering almost every possible cloud need from compute and storage to advanced AI and IoT.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?
I would recommend Microsoft Azure. It has the best integration with Microsoft products such as Windows Server, Office 365, Active Directory, and other Microsoft tools, making it easier for companies already using Microsoft technologies.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?
Google Cloud Platform is widely recognized for Artificial Intelligence, Machine Learning, and Kubernetes. Google created Kubernetes and has strong AI/ML services such as Vertex AI and TensorFlow support.

### 4. What similarities did you observe among the three cloud providers?
All three cloud providers offer similar core infrastructure services such as compute, storage, networking, and identity management. They all allow users to create virtual machines, store data, create virtual networks, and control access using IAM services.
