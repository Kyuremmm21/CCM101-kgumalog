# Laboratory 05 – Cloud Data Engineer

## Mission Overview
In this laboratory activity, I was tasked to deploy an S3-compatible Object Storage server using MinIO on Docker. The goal was to create a proof-of-concept storage environment for a photo-sharing application by setting up MinIO, creating a bucket named `client-photos`, and uploading a test file.

## Objectives
- Differentiate between Block, File, and Object Storage
- Deploy an S3-compatible Object Storage server (MinIO) using Docker
- Access a cloud service via a web interface using port forwarding
- Create a storage bucket and upload objects (files)
- Document cloud storage operations using Markdown

## Tools Used
- KillerCoda Ubuntu Playground
- Docker
- MinIO (quay.io/minio/minio)
- GitHub
- Web Browser

## Skills Learned
- Deploying containerized object storage using Docker
- Using environment variables in Docker
- Accessing services through port forwarding
- Creating and managing buckets in MinIO
- Documenting technical steps in Markdown
