# Security Audit Report – Laboratory 08

## Principle of Least Privilege (PoLP)
The Principle of Least Privilege means giving users and programs only the minimum permissions they need to do their job. In the cloud, this is very important because if an account gets hacked, the attacker can only do limited damage. It helps protect the whole system from big security problems.

## Attack Surface
The attack surface is all the possible ways an attacker can try to enter or attack a virtual machine. This includes open ports, running services, and software that is exposed to the internet. The larger the attack surface, the easier it is for hackers to find a way in.

## Default Deny Policy
A Default Deny policy means the firewall blocks all incoming traffic by default. Only the ports that you specifically allow can get through. This is safer than trying to block every possible attacker one by one, because you might miss some dangerous traffic.
