## Checkpoint 7 – Linux Investigation

I launched a KillerCoda Playground and used the following Linux commands to check the system:

- `cat /etc/os-release` → to identify the Operating System
- `lscpu` → to get CPU information
- `free -h` → to check Memory
- `df -h` → to check Disk Space

### If this Linux server were migrated to the cloud, which services could host it?

- **AWS**: Amazon EC2
- **Azure**: Azure Virtual Machines
- **GCP**: Compute Engine

These services allow you to create virtual machines that can run the same Linux operating system with similar CPU, memory, and disk configuration.
