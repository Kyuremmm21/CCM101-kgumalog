## Answers to Questions

**1. Which cloud provider offers the broadest range of services?**

AWS offers the broadest range of services. It has the most services compared to Azure and Google Cloud. Because it started earlier, it already has tools for almost every need.

**2. Which provider best integrates with Microsoft technologies?**

Microsoft Azure is the best when it comes to Microsoft technologies. It works smoothly with Windows Server, Microsoft 365, and Active Directory. This makes it easier for companies that already use Microsoft products.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**

Google Cloud is the strongest in Artificial Intelligence and Kubernetes. It has good tools for machine learning and its managed Kubernetes service (GKE) is one of the best. Many people choose GCP for AI projects.

**4. Which cloud platform would you personally choose and why?**

If I have to choose one, I would pick AWS. It has the most services and a lot of documentation and tutorials online. Even though the other two are also good, AWS feels safer for beginners like me because there are more resources to learn from.
