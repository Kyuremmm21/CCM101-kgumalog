# Google Cloud Platform Research

## Brief Overview
Google Cloud Platform (GCP) is Google’s cloud service. It started with App Engine in 2008. It uses the same infrastructure that runs Google Search, YouTube, and Gmail.

## Global Infrastructure
GCP has around 40+ regions and 130 zones. Google has a very strong private global network that makes data transfer fast.

## Cloud Management Console
You use the Google Cloud Console in the browser. There is also gcloud command-line tool.

## Four Core Services
1. **Compute Engine** – Virtual machines.
2. **Cloud Storage** – Object storage.
3. **Virtual Private Cloud (VPC)** – Networking.
4. **Cloud IAM** – Identity and access management.

## Three Advantages
1. Excellent for Artificial Intelligence, Machine Learning, and data analytics (BigQuery, Vertex AI).
2. Best managed Kubernetes service (GKE).
3. Clean and simple pricing with automatic discounts.

## Typical Enterprise Use Cases
- AI and machine learning projects
- Big data analytics
- Container and Kubernetes workloads
- High-performance global applications
