# Client Recommendations

## Client A – Startup Company

**Recommended Platform:** AWS

A startup that wants to launch a mobile app with limited budget needs something cheap to start but can grow fast later. AWS is a good choice because it has a free tier and you only pay for what you use. It also has many tools that help apps scale automatically when more users come.

**Useful services:**
- Amazon EC2 (for running the app servers)
- Amazon S3 (for storing images and files)
- Amazon RDS (for the database)

---

## Client B – University

**Recommended Platform:** Microsoft Azure

The university already uses Windows Server, Microsoft 365, and Active Directory. Azure works very well with these Microsoft tools, so moving some services to the cloud will be easier and less problematic. It also supports hybrid setups, which is helpful for schools that still keep some servers on campus.

**Useful services:**
- Azure Virtual Machines
- Microsoft Entra ID (for identity and access)
- Azure Blob Storage or Azure Files

---

## Client C – AI Research Company

**Recommended Platform:** Google Cloud Platform

This company focuses on Artificial Intelligence and Machine Learning that need high-performance computing. Google Cloud is strong in AI and has special tools and hardware (like TPUs) that are good for training models. Their platform is also known for handling big data and analytics well.

**Useful services:**
- Compute Engine (with GPU or TPU options)
- Vertex AI
- Cloud Storage

---

## Client D – Global E-Commerce Company

**Recommended Platform:** AWS

A global online shopping company needs infrastructure that stays online all the time and can handle sudden increases in traffic. AWS has the largest global network of data centers and very mature tools for automatic scaling and high availability. This makes it a safe choice for businesses that serve customers in many countries.

**Useful services:**
- Amazon EC2 with Auto Scaling
- Amazon S3
- Amazon CloudFront (for faster delivery of content)
- Amazon RDS

---

## Multi-Cloud Decision Matrix

| Business Requirement       | Recommended Platform | Justification |
|---------------------------|----------------------|-------------|
| Startup Company           | AWS                  | Affordable to start and easy to scale later |
| Enterprise Organization   | AWS or Azure         | Mature services and good support for large companies |
| Microsoft Environment     | Azure                | Best integration with Windows, Microsoft 365, and Active Directory |
| AI / Machine Learning     | Google Cloud         | Strong tools and hardware for AI and data work |
| Kubernetes Deployment     | Google Cloud         | GKE is widely considered one of the best managed Kubernetes services |
| Global Web Application    | AWS                  | Biggest global infrastructure and reliable auto-scaling |
