# AWS Research

## Brief Overview
Amazon Web Services (AWS) is the biggest and oldest public cloud platform. Amazon started it in 2006. It gives companies computing power, storage, and many other services over the internet so they do not need to buy their own servers.

## Global Infrastructure
AWS has many data centers around the world. It has about 39 Regions and more than 120 Availability Zones. This helps applications stay fast and online even if one place has a problem.

## Cloud Management Console
You can manage everything using the AWS Management Console in your web browser. There is also a command-line tool called AWS CLI and mobile apps.

## Four Core Services
1. **Amazon EC2** – Virtual servers (computers) that you can start and stop anytime.
2. **Amazon S3** – Object storage for files, pictures, videos, and backups.
3. **Amazon VPC** – Private network inside AWS so your resources stay secure.
4. **AWS IAM** – Controls who can access what in your account.

## Three Advantages
1. Very big selection of services (more than 200).
2. High reliability and global reach.
3. Strong free tier and pay-only-for-what-you-use pricing.

## Typical Enterprise Use Cases
- Hosting websites and mobile apps
- Big data and analytics
- Running machine learning models
- Backup and disaster recovery
