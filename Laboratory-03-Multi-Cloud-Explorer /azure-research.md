# Microsoft Azure Research

## Brief Overview
Microsoft Azure is Microsoft’s cloud platform. It started in 2010 (first called Windows Azure). It works very well with Windows, Microsoft 365, and Active Directory.

## Global Infrastructure
Azure has the most regions among the big three clouds (more than 60 regions). It also has many Availability Zones for high availability.

## Cloud Management Console
You manage Azure using the Azure Portal in the browser. There is also Azure CLI and PowerShell.

## Four Core Services
1. **Azure Virtual Machines** – Virtual servers for Windows or Linux.
2. **Azure Blob Storage** – Storage for large amounts of unstructured data.
3. **Azure Virtual Network** – Private networking.
4. **Microsoft Entra ID** (formerly Azure AD) – Identity and access management.

## Three Advantages
1. Best integration with Microsoft products (Windows Server, Office 365, Active Directory).
2. Strong hybrid cloud options (you can connect on-premises servers easily).
3. Good for enterprises that already use Microsoft tools.

## Typical Enterprise Use Cases
- Migrating Windows servers to the cloud
- Running Microsoft 365 and Active Directory in the cloud
- Enterprise applications and databases
- Hybrid cloud setups
