# Reflection – Laboratory Activity 1: Welcome to the Cloud

## What I Learned
In this laboratory activity, I learned how to use a cloud-based Linux environment through KillerCoda. I also learned how to navigate the Linux terminal, gather basic system information, organize files and directories, and create a professional GitHub repository. Additionally, I practiced writing technical documentation using Markdown, which is an essential skill for cloud engineers.

## Challenges Encountered
At the beginning, I found it a bit challenging to create a new user account and switch to it. Some commands also required several attempts before I could get the correct output, especially when collecting system information such as CPU details, memory, and disk space. Organizing the folder structure and uploading screenshots to GitHub also took some time to get right.

## How I Overcame the Challenges
I carefully re-read the instructions and tested the commands one by one. I used the man command and online references to better understand each Linux command. For GitHub, I followed the step-by-step process of creating a repository, adding files, committing changes, and pushing them to the remote repository.

## Skills Gained
- Basic Linux navigation and file management
- Gathering system information using terminal commands
- Creating and organizing directory structures
- Writing technical documentation using Markdown
- Creating and managing a GitHub repository
- Applying proper documentation practices used by cloud professionals

## Personal Insight
I realized the importance of proper documentation and version control from the very beginning. This portfolio will serve as a complete record of my progress throughout the course. I now feel more confident in using the Linux terminal and GitHub, which will be the foundation for the upcoming laboratory activities.

## Future Application
I will apply the knowledge and skills gained from this activity in future labs, especially those involving Docker, Kubernetes, and cloud infrastructure. I will also continuously update this GitHub portfolio so that by the end of the semester, I will have a solid and professional record of my work.
